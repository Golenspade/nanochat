# Scaled V4.1 Text Backbone Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A trainable and generative small V4.1-style text model with structural fidelity, explicit approximations and real GPU evidence.

**Architecture:** Keep the verified dense-reuse baseline at `8d42d19`. Implement a separate `DeepSeekV41` model with latent local/global attention, non-overlapping compression, Full/Reindex/Reuse routing, CED, MoE, Single-Pass mHC, Engram and packed FP4 global storage. Use a portable PyTorch implementation; separate correctness from kernel speed claims.

**Tech Stack:** Existing PyTorch/argparse/checkpoint/Engine APIs, pytest, Colab CLI on an isolated A100.

## Global Constraints

- Preserve COMPUTE_DTYPE and fp32 master weights; meta construction followed by explicit initialization.
- Preserve original GPT and existing checkpoints. New architecture is opt-in and never loaded from dense weights implicitly.
- Pin report SHA-256 and official inference revision; carry MIT notices for adaptations.
- Implement inline, keep original Colab training running, release only sessions created for this experiment.
- No quality-equivalence or hardware-kernel claims from shape tests or a short pilot.
